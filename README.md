# The Smasher

An icy arcade air hockey game you play in the browser. Mouse on PC, touch on phones.

**Play:** https://assaling4.github.io/the-smasher/

Single file (`index.html`), no install needed.

- Single Player works offline.
- Accounts, Friends and Play with friend need a free Supabase project: see [online/SETUP.md](online/SETUP.md).
- Test online play on one computer without Supabase: open `index.html?mock=1` in two tabs.
